# 桌面宠物助手（Desktop Companion）

> 一个**轻量、本地优先、规则驱动**的桌面宠物助手
> 版本 **v1.0.0** · C++17 / Qt 6.5.3 · 已构建并实测启动成功

---

## 这是什么

一个常驻桌面的桌宠，你可以用**说话的方式**让它帮你做事：

- 打开程序、打开文件夹
- 搜索、翻译、朗读文字
- 所有涉及系统改动的操作，**都必须先经过你的授权**

### 三条硬约束（来自需求规格说明书）

| 约束                                 | 落实情况                                   |
| ---------------------------------- | -------------------------------------- |
| **不使用大语言模型 / 不使用生成式 AI / 不使用深度学习** | 全部命令识别靠**规则匹配**，语言识别靠**字符集统计**，无任何模型文件 |
| **轻量、低资源、本地优先**                    | 核心功能完全离线；不需管理员权限；进程常驻内存占用低             |
| **最小权限、可解释、模块可替换**                 | 默认普通用户运行；永不静默提权；每个服务都是可替换接口            |

### 它明确不做的事

- ❌ 不联网也能用核心功能
- ❌ 不收集你的数据（历史只存本地）
- ❌ 不暗中提权（绝不写 HKLM，绝不需要管理员）
- ❌ 不用 Live2D / 3D
- ❌ 不会在你拒绝后换个路径再试一遍

## 快速开始（30 秒）

### 方式一：直接运行成品（推荐）

```
1. 进入 dist/DesktopCompanion-portable/
2. 双击 DesktopCompanion.exe
3. 右下角托盘出现图标，桌面出现桌宠 —— 完成
```

**无需安装，解压即用。** 约 37 MB，含全部 Qt 运行时。

### 方式二：从源码构建

```bash
cd DesktopCompanion

cmake -S . -B build -G Ninja \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_CXX_COMPILER=g++ \
  -DCMAKE_PREFIX_PATH="<项目绝对路径>/toolchain/6.5.3/mingw_64" \
  -DDC_BUILD_TESTS=OFF

cmake --build build -j 6
# → [11/11] Linking CXX executable bin\DesktopCompanion.exe
```

> ⚠️ `CMAKE_PREFIX_PATH` **必须用绝对路径且加引号**（工作区路径含空格）。
> 完整说明见 `docs/BUILD_AND_COMPAT.md`。

## 核心设计亮点

### 1. 单一收口点 —— 权限无法被绕过

界面层**根本拿不到** `SystemService` 的头文件。所有交互必须经过 `IntentRouter`：

```
UI ──handle(req)──> IntentRouter
                      ├─ 低风险 ────────────> 执行
                      └─ 中/高风险 ─> 挂起，返回（一行都不执行）
                                       emit authorizationRequired
                                              │
UI 弹权限对话框，用户决定 ────────────────────┘
                                              │
UI ──resolveAuthorization(granted, scope)────> 继续或拒绝
```

**"绕过权限"在这套结构里没有代码路径可走** —— 这是结构性保证，不是纪律要求。

### 2. 三层风险 + 三档授权

| 风险   | 行为                   |
| ---- | -------------------- |
| 低    | 直接执行                 |
| 中    | 弹确认框                 |
| 高    | 弹授权对话框（展示目标/影响/所需权限） |
| 禁止   | 永不执行，且拒绝后不得换路径重试     |

授权范围**默认"仅此一次"**（最小授权），想放宽必须自己主动选。

### 3. 双层能力探测 —— 不静默失效

一个功能要开放，**两道关都得过**：

- **编译期**：CMake 探测（`generated/core/BuildConfig.h`）
- **运行期**：系统 API 实际是否可用（`SystemInfo`）

任一不过，功能入口关闭，**并明确告诉你"哪个功能不可用 + 为什么 + 什么还能用"**。

### 4. 可替换服务 —— 换后端不改业务代码

语音、翻译、网络等服务都是**纯虚接口**。例如换语音后端只需实现 `SpeechBackend` 并注册，`SpeechService` **一行不改**。

### 5. 目录即架构

```
model → core → platform → engine → services → ui
```

依赖**严格单向**。下层不知道上层存在。这让"可替换""不可绕过"变成结构事实。
